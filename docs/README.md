# La documentation

Chaque guide explique une étape du projet : le but, comment s'en servir, puis comment c'est fait.
Ils sont rangés ici par sujet ; le numéro d'étape donne l'ordre où ils ont été écrits. Quand un
guide couvre plusieurs étapes, elles sont indiquées entre parenthèses.

Pour commencer, le premier guide de chaque partie suffit : on y revient pour le reste quand on en
a besoin.
